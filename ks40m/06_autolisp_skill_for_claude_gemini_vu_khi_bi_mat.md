# Hướng dẫn cài đặt

## Bước 1 — Bật hiển thị folder ẩn

Thư mục `.claude`, `.gemini` thường bị Windows ẩn.

Thực hiện:

1. Mở File Explorer
2. Chọn tab **View**
3. Chọn:
   - **Show → Hidden items** (Windows 11)
   - hoặc tick trực tiếp **Hidden items** (Windows 10)

## Bước 2 — Mở thư mục cài skill

### 1. Cài cho Claude Code

Mở File Explorer, click vào thanh địa chỉ và paste:

```
%USERPROFILE%\.claude\skills\
```

Sau đó nhấn Enter và copy folder `autolisp` vào.

![Cài đặt skill cho Claude](https://lenotestore.blob.core.windows.net/uploads/images/1778831724157-0xhpx9.gif)

### 2. Cài cho Gemini CLI

Paste đường dẫn:

```
%USERPROFILE%\.gemini\skills\
```

Sau đó copy folder `autolisp` vào.

### 3. Cài cho Antigravity

#### Global (khuyến nghị)

```
%USERPROFILE%\.gemini\antigravity\skills\
```

#### Workspace-only

```
<workspace>\.agents\skills\
```

Sau đó copy folder `autolisp` vào.

![Cài đặt skill cho Gemini và Antigravity](https://lenotestore.blob.core.windows.net/uploads/images/1778831904327-7com36.gif)

### Antigravity — Global hay Workspace?

#### Global

- Dùng cho mọi project
- Chỉ cần cài một lần
- Khuyến nghị cho skill dùng chung như `autolisp`

#### Workspace

- Chỉ áp dụng cho một project cụ thể
- Phù hợp khi share repo với team

Đa số trường hợp nên dùng **Global**.

### Nếu báo lỗi “không tìm thấy folder”

Folder `skills` chưa tồn tại. Tạo thủ công:

1. Mở:
   - `%USERPROFILE%\.claude\`
   - `%USERPROFILE%\.gemini\`
   - `%USERPROFILE%\.gemini\antigravity\`

2. Nếu folder chưa có:
   - Chuột phải → **New → Folder**
   - Tạo `.claude` hoặc `.gemini`

3. Vào bên trong và tạo tiếp folder `skills`.

## Bước 3 — Copy folder `autolisp`

Copy nguyên folder:

```
autolisp
```

vào thư mục:

```
skills
```

Cấu trúc đúng:

```
skills/
└── autolisp/
    ├── SKILL.md
    ├── references/
    └── assets/
```

### Lỗi phổ biến

Sai cấu trúc:

```
skills/autolisp/autolisp/SKILL.md
```

Nếu bị lồng 2 lần:
- Kéo folder bên trong ra ngoài
- Xóa folder rỗng

## Bước 4 — Restart platform

Bắt buộc restart hoàn toàn:

| Platform | Cách restart |
| --- | --- |
| Claude Code | Đóng hẳn cửa sổ rồi mở lại |
| Gemini CLI | Mở terminal session mới |
| Antigravity | Thoát hoàn toàn rồi mở lại |

## Bước 5 — Test skill

Mở chat và nhập:

```
Viết LISP command MAKE_GRID vẽ lưới trục kết cấu.

Input:
1. "Select a base point:" — điểm gốc
2. "Enter X spans (Ex: 4000x4,5000,6000):" — không nhập thì thoát
3. "Enter Y spans (Ex: 4000x4,5000,6000):" — không nhập thì thoát
4. "Enter extensional space:" — mặc định 1000

Quy tắc span: hỗ trợ 6000x2 → 6000,6000 và mix 6000x2,5000 → 6000,6000,5000. Cách nhau bằng dấu phẩy.

Cách vẽ: từ điểm gốc cộng dồn X spans vẽ đường đứng, cộng dồn Y spans vẽ đường ngang, mỗi đường kéo dài thêm extent ở hai đầu, vẽ trên layer hiện tại.
```

Nếu skill hoạt động đúng, AI sẽ:
- chia hàm rõ ràng
- có validation input
- xử lý lỗi đầy đủ
- comment chi tiết
- dùng cấu trúc AutoLISP chuyên nghiệp hơn hẳn

Nếu chưa kích hoạt đúng, thêm:

```
Use the autolisp skill.
```

ở đầu prompt.

## Cài cho nhiều platform cùng lúc

Bạn có thể copy cùng một folder `autolisp` vào nhiều thư mục:
- `.claude\skills`
- `.gemini\skills`
- `.gemini\antigravity\skills`

Không có xung đột.

## Gỡ skill

Xóa folder `autolisp` trong thư mục `skills`, sau đó restart platform.

## Troubleshooting

- **Không thấy `.claude` hoặc `.gemini`**: Chưa bật hiển thị folder ẩn.
- **Đã cài nhưng AI vẫn viết LISP kém**: Kiểm tra `SKILL.md` có nằm trực tiếp trong `skills/autolisp/` chưa; restart platform; thêm `Use the autolisp skill`.
- **File `.skill` không mở được**: Đổi đuôi `.skill` thành `.zip` rồi giải nén.
